# Fairlight 2, ZX Spectrum

This repo aims to document the data structures and behaviour of the ZX Spectrum
version of Fairlight 2. This is in order to try and find out why the game seemingly
can't be completed, and whether there is a sensible change which could be to fix this in
line with the original intentions (if possible).

Inspiration taken from https://github.com/VilleKrumlinde/FairlightZ80/tree/main
